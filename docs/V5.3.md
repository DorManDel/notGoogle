## V5.3.1 — Footer wrapper refinement (review-only)

User feedback: climate text belongs **above** navigation, independently centered in the footer. Previously it was an absolutely positioned child of `.foot-links`; this was fragile for RTL, tablet, mobile and split-screen widths.

Changes:
- New `.footer-wrap` contains a dedicated `.climate-row` and a semantic `<nav class="foot-links">`, plus the existing country row above.
- Climate link now participates in normal document flow: **no absolute positioning**, no artificial top offset or `order:3` hacks.
- Responsive nav gets its own container for legal and product links, with wrapping only where needed.
- Fixed RTL badge stretching when both `left` and `right` were inherited from prior CSS.
- Changed only `index.html` footer markup and `styles/pixel-v5.3.css`; retained all JS, search destinations and fictional-only login unchanged.
- Bumped stylesheet query version to `?v=5.3.1` for browser cache busting.

Local Chromium smoke checks on a *representative older V5 homepage template* with the V5.3.1 CSS, widths `320, 390, 600, 768, 940, 1194, 1440` (viewport heights varied): no document horizontal overflow, no climate/nav bounding-box overlap, no stretched badge, no badge/footer overlap and no JS errors. Footer heights: **150–156px** at 320–600, **126px** at 768–1440. These are test-render measurements, not direct Google measurements; latest V5.2 interactive markup still needs a real-device review.

### Wordmark/font investigation
The reference's letter shapes cannot be made identical by tuning `font-size` or `letter-spacing` in Arial: Google's logotype uses custom designed glyphs. Adding an `<svg><text>` that still uses Arial would not fix those glyph differences. We have therefore **not** changed the active wordmark or imported an exact corporate SVG in this structural footer fix. A separate typography A/B review should compare legal, accessible independent design alternatives with the same bounding box and zoom, retaining the demo identifier.
