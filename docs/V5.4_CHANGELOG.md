## V5.6 — AI pointer-tracking prism + built-in comparison
- The AI pill now has **no colored glow at rest**. Its neutral surface is always visible.
- A cluster of **blue, green, yellow, orange** radial gradients uses the same pointer position variables (`--ai-x` / `--ai-y`), so all four highlights travel **together** with the cursor.
- Localized radial masking clips color to the immediate pointer neighborhood; the component also clips glow to its border.
- CSS hover, focus-visible and active states reveal color. Pointer exit returns the pill to neutral. `prefers-reduced-motion` disables transitions.
- The Visual Comparison tab now embeds a historical side-by-side reference screenshot. The file is a **compressed thumbnail**, marked as a historical comparison; selecting full-resolution source screenshots remains possible via the existing local-only comparison viewer.
- Playwright tests validate: gradient hidden at rest, position changes from left to right on hover, gradient disappears after exit, image decodes, four lab tabs work across the tested viewports.
- **Important:** the visual effect is our independently authored reconstruction, not confirmed Google source code. No claim of pixel-identical fidelity.
